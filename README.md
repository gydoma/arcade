## SASS Compiler
A stílusa a weboldalnak SASS-ban íródott, semmilyen könyvtárat nem használtunk a sajátos dizájn miatt.
### SASS CLI Compiler letöltése
```sh
npm install -g sass
```
### Compiler futtatása:
```sh
sass --watch --verbose scss/config.scss style.css
```
